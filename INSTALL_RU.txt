================================================================
  Yandex Sheets UI Fix — Инструкция по установке (RU)
================================================================

ЧТО ЭТО?
--------
Небольшой CSS-стиль, который делает нижнюю панель с вкладками
листов в Яндекс Таблицах крупнее и удобнее для чтения.
Размеры подобраны близко к Google Sheets, но чуть комфортнее.

ЧТО НУЖНО?
----------
1. Браузер: Chrome, Яндекс Браузер, Edge или любой на Chromium.
2. Расширение Stylus (бесплатное):
   - Chrome Web Store:
     https://chrome.google.com/webstore/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne
   - Для Яндекс Браузера — то же расширение из Chrome Web Store
     (Яндекс Браузер поддерживает расширения Chrome).

УСТАНОВКА
---------
1. Установите расширение Stylus.
2. Откройте Яндекс Таблицу в браузере.
3. Нажмите на иконку Stylus в панели браузера.
4. Выберите "Написать новый стиль" / "Create new style".
5. В поле "Применить к" (Applies to) выберите вариант "ВСЕ"
   (или "URL-адреса, начинающиеся с" -> оставьте пустым,
   чтобы стиль применялся ко всем сайтам).
   ВАЖНО: автор стиля не нашёл точного URL, который использует
   Яндекс Таблицы, поэтому рекомендуется выбрать "ВСЕ".
   Это безопасно: стиль использует очень специфичные селекторы
   (#statusbar_bottom ...), которые есть только в Яндекс Таблицах.
6. Вставьте CSS-код из файла styles/sheet-tabs.css
   (или styles/sheet-tabs-var4.css).
7. Сохраните (Ctrl+S).
8. Обновите страницу с таблицей — вкладки должны стать крупнее,
   а активная вкладка — подсветиться зелёным.

НАСТРОЙКА ПОД СЕБЯ
------------------
Все параметры меняются в CSS. Основные:
- height:       высота вкладок (по умолчанию 36px).
- font-size:    размер текста (14px).
- padding:      внутренний отступ (0 1px).
- margin-right: зазор между вкладками (4px).
- background-color: цвет подсветки активной вкладки
                (#79d69361 — зелёный с прозрачностью).

Если что-то не работает — проверьте, что стиль включён
(иконка Stylus должна быть активной), и что вы находитесь
на странице Яндекс Таблиц.
